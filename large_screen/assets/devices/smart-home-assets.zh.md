# 家居面板素材拆分

源图：[smart_home_reference.png](smart_home_reference.png)，2048 × 1184。11 张 PNG 已转换为固件只读图像并接入家居页面，从首页家居标题进入。实际布局、触摸及业务接口见 [家居面板接入说明](../../docs/smart-home-integration.zh.md)。下表保留素材拆分信息。

## 透明 PNG

新增资源使用 `smart_home_` 前缀，与已有 `home_` 首页资源区分。

| 湿度 | [smart_home_humidity.png](smart_home_humidity.png) | 24 × 24 | 原图实际是蓝色太阳状符号，并非标准湿度符号 |
| 灯光 | [smart_home_light.png](smart_home_light.png) | 24 × 24 | 同时复用于回家模式、联动按钮，不存重复图 |

11 张 PNG 文件共 16,336 字节，约 16 KiB。均为透明 RGBA，四周保留完全透明的外边缘。由合成原图估算去底，金属暗部、原图阴影和细风线有近似，不能恢复原始设计图层。小图标按功能位置命名不等于确认其设备含义；原图存在符号和标签不一致，应在业务实现时确认。

原图最右能耗卡也使用门状图片，语义不明确，因此不另存重复门图；能耗区域建议使用已有字体中的 `LV_SYMBOL_CHARGE`，数值和 kW 单位独立绘制。窗帘下面的原图文字也不能作为可靠设备状态，开合状态应由业务数据明确提供。不裁切右下角来源标记，也不把它作为界面资源。

## 原生控件对应

| 元素 | LVGL v8 实现 | 动态与交互 |
| --- | --- | --- |
| 大时钟、日期、星期 | `lv_label` + 子集字体 | 独立更新，不使用原图文字位图 |
| 客厅、卧室、厨房、书房 | 多个 `lv_btn` + 选中样式 | 点击切换房间数据源；一次只选中一个房间 |
| 温度、湿度、空气质量、风速 | `lv_label` + 图标 | 值与单位分开管理，动态更新；空气质量等级需由真实指标定义 |
| 四张环境卡与六张设备卡 | `lv_obj` + 深灰渐变、边框、圆角 | 不切背景，不把数值、状态固化到 PNG |
| 灯光与 72% | `lv_slider` + 百分比标签 | 在原卡片内增加符合触摸习惯的亮度控制，收到真实回执后同步百分比 |
| 空调 | `lv_img` + 数字输入或增减按钮 + 开关 | 图只表示设备，24 等设定值用标签，避免多个温度版本的图片 |
| 新风 | 图标 + `lv_switch` / 可选按钮 | 开关、风速由真实状态驱动，拒绝或超时后恢复状态 |
| 窗帘 | 设备图 + 开/停/关按钮或开度滑块 | 图形不等于开合状态，百分比和动作需单独显示 |
| 门锁与布防 | 门锁图、盾牌图 + 状态标签与按钮 | 解锁和撤防需确认及权限校验；不能仅靠本地切换颜色认定成功 |
| 能耗 | `lv_label` + 电量符号 | 实际应区分瞬时功率 kW 与累计电量 kWh，不照搬含糊标签 |
| 回家、离家、观影、睡眠 | `lv_btn` + 图标 + 选中样式 | 命令受理与实际场景执行结果分开处理，失败时不显示成功状态 |
| 联动已开启 | 可选按钮或 `lv_switch` + 灯光图标 | 已启用状态用样式及标签表达，不保存蓝色/灰色两套图片 |
| 顶部网络状态 | `lv_line` / 简单对象、已有字体符号 | 实际信号格数和网络状态动态更新；不切不明确的原图状态符号 |
| 分隔线、页面背景 | 原生边框或背景样式 | 不使用整页纹理图，减少 Flash 与刷新成本 |

不要将开关、滑块或场景按钮本身切成图，PNG 只承载视觉图标。可点击对象的区域不能等于小图标的像素大小，应保留约 40–44 像素的有效触摸高度。设备按钮与卡片入口要明确事件归属，避免操作开关同时跳转页面。

## 480 × 320 与内存建议

- 原图较宽，不简单整体缩小。当前实现保留四房间、四项环境数据、六张设备卡和五个场景/联动按钮；复杂设备操作放入独立弹层，按实际像素显示图标。
- 温度、湿度蓝色符号和空调、窗帘、门锁可用 RGB565 + alpha8，保持其颜色和金属明暗。这五张像素数据合计 26,880 字节。
- 灯光、盾牌、三种场景图标以及新风可用 alpha8，合计 4,032 字节，用 `img_recolor` / `img_recolor_opa` 设置正常、禁用、选中颜色。忽略原图中灰色细线的色差，只保留透明度。
- 以上混合方案共 30,912 字节，约 30.2 KiB，不含描述符、对齐和字体；全部用 RGB565 + alpha8 则是 38,976 字节。这些是转换后的像素大小，不是 PNG 压缩文件大小。
- 单色图可进一步使用 4 位 alpha，但先检查小型盾牌、风线和场景符号是否仍清晰。若温湿度图也统一为主题色，可改为单通道透明度以继续节省 Flash。
- 推荐离线转换成只读 `const lv_img_dsc_t`，不为小图引入运行时 PNG 解码器，不做运行时缩放，不另存按下、开启和关闭等重复图片。
- 文字需生成覆盖标题、房间名称、单位与标点的子集字体；所有 LVGL 更新应在 LVGL 任务内执行，设备命令通过非阻塞回调转交业务层。

## 生成与检查

运行 VS Code 任务 **Extract Smart Home Assets**，或在项目根目录执行：

```powershell
& .\tools\extract_smart_home_assets.ps1
```

脚本检查 2048 × 1184 源图尺寸、每张 PNG 的输出尺寸、非空内容及透明外边缘，并生成系统临时目录下的 `lvgl-smart-home-assets-preview.png` 深浅底预览。已人工检查设备轮廓和图标，无相邻文字或卡片边框。该图是素材预览，不是家居页 LVGL 渲染或实机效果。

VS Code 任务 **Convert Smart Home Assets** 将这些 PNG 转为 `lvgl_smart_home_images.c`，检查尺寸、透明边缘及像素总量。任务 **Test LVGL Home** 编译实际 LVGL 页面，输出 [家居页渲染](../../docs/lvgl-smart-home-preview.png) 和 [亮度控制渲染](../../docs/lvgl-smart-home-control-preview.png)。
