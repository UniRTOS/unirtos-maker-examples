# 工业面板素材拆分

源图为 [industry_reference.png](industry_reference.png)，尺寸 604 × 337。目标设备为 480 × 320，使用原生控件重新排版，不将整页缩放为背景图。工业页已接入首页入口，见 [工业面板接入](../../docs/industry-integration.zh.md)。

## PNG 素材

| 功能 | 文件 | 尺寸 | 说明 |
| --- | --- | --- | --- |
| 告警入口 | [industry_alarm.png](industry_alarm.png) | 32 × 32 | 白色三角感叹号，RGBA 透明背景，不含按钮底座 |

文件为 634 字节。仅提取这一张图标是为了减少资源，不缺少其他功能：其余元素都可用原生控件高效绘制。图标由合成原图估算透明度提取，边缘为近似，不是原始矢量素材。既有 `alarm.png` 等资源保持不变。

## 原生控件对应

| 功能区域 | LVGL v8 实现 | 动态与交互 |
| --- | --- | --- |
| 时间、日期 | `lv_label` + Montserrat 字体 | 独立更新，不将参考图中的时间烧入图片 |
| 告警入口底座 | `lv_btn` + 圆角、底色 + `lv_img` | 点击显示告警列表，告警颜色通过图标重着色表达 |
| 实时趋势 | `lv_chart`，折线模式、原生网格 | 实时采样追加数据；稀疏采样时保留真实折线，不为模仿光滑曲线伪造采样值 |
| 产线负载 | 竖直 `lv_bar` + 独立百分比 `lv_label` | 0–100 范围，动态修改柱高与数值；不切静态柱图 |
| 油温仪表 | 两至三个非交互 `lv_arc` + `lv_line` 指针 + `lv_label` | 根据实际量程换算指针角度；装饰分段用原生圆弧绘制 |
| 油压仪表 | 复用相同的圆弧和指针实现 | 单独设置压力量程、单位和数值，不额外保存一套表盘位图 |
| 在线设备、告警数量 | `lv_label` | 使用真实在线状态及告警计数更新 |
| 阀门开关 | `lv_switch` + 主体、指示器、旋钮样式 | 处理 `LV_EVENT_VALUE_CHANGED`；命令拒绝或超时后同步真实状态 |
| 六个区域背景 | `lv_obj` + 圆角、边框、深色样式 | 无复杂纹理，不切卡片背景图 |
| 页面背景 | 屏幕样式，必要时轻微渐变 | 不保留原图背景纹理，减少 Flash 占用和绘制负担 |

圆弧与指针用于显示，不添加可拖动输入，避免误操作。开关至少保留约 44 像素高的有效触摸区域；告警按钮同样需要足够大的点击底座，不以图标可见像素作为触摸范围。

## Flash 与 RAM

- 告警符号为单色，建议离线转成 `LV_IMG_CF_ALPHA_8BIT`：32 × 32 = 1,024 字节像素数据。通过 `img_recolor` 和 `img_recolor_opa` 设置正常与告警颜色。
- 若细线观感允许，可用 4 位 alpha：32 × 32 / 2 = 512 字节。若最终显示为 24 × 24，alpha8 为 576 字节，建议离线缩小，不运行时缩放。
- 无须为无告警、告警、按下、禁用状态分别存 PNG；按钮样式和图标重着色即可区分。
- PNG 的 634 字节是磁盘压缩大小，不等于 LVGL 静态数组或解码内存。推荐生成只读 `const` 图片描述符，不为单个图标引入 PNG 解码器。
- 两个仪表、趋势图、开关和卡片均无图片像素数组占用，但仍有 LVGL 对象、样式和图表序列的运行内存。趋势可固定保留 24 或 32 个点，避免无限缓存。
- 当前工程已启用 `LV_USE_CHART`、`LV_USE_BAR`、`LV_USE_SWITCH`、`LV_USE_LINE` 和 `LV_USE_ARC`。无需为了两个仪表开启更重的完整仪表控件。
- 中文标题、单位和标点需进入实际字体覆盖检查。所有控件和状态更新必须在 LVGL 任务中执行，硬件回调不得阻塞界面。

## 重新生成

项目根目录执行：

```powershell
& .\tools\extract_industry_assets.ps1
```

也可运行 VS Code 任务 **Extract Industry Assets**。脚本按源图比例定位告警符号，移除深色底色，输出透明 PNG，并检查有效像素和完全透明的外边缘。默认源图与输出均位于本目录。

素材验证：32 × 32、255 个非全透明像素、四周外边缘全透明，人工检查图标轮廓及感叹号完整。`tools/convert_industry_assets.ps1` 已生成 `lvgl_industry_images.c`，像素数据为 1,024 字节 alpha8，已加入 CMake 源列表；完整固件链接与实机验收尚未完成。
