# 小智桌面机器人

[English](README.md)

小智桌面机器人方案是一个基于 UniRTOS 与小智 AI（xiaozhi）开放协议构建的智能语音桌面机器人。它以移远 EG800Z 模组为端侧运行基础，接入小智 AI 服务完成语音对话与端侧工具调用，在一块 360×360 圆形触摸屏上显示表情动画、表盘时钟与设备状态，并可通过语音指令驱动头部步进电机转动、调节喇叭音量。

本项目重点展示 UniRTOS 在持续语音交互、屏幕渲染、触摸交互、设备端 MCP 工具调用（电机 / 音量）以及蜂窝网络 TLS 接入方面的能力，可作为 AI 语音终端、桌面陪伴机器人、端云协同交互设备的参考示例。

## 功能特性

- 连接后自动持续监听，客户端 VAD 自动识别语音结束并发送，无需反复点击；回复结束自动继续监听。
- 360×360 圆形触摸屏：眼睛表情动画、表盘时钟、状态与六位验证码页面；单击开始/结束对话、左右滑动切换表情、长按表达开心。
- 设备端 MCP 工具：通过语音指令驱动头部电机（左转 / 右转 / 摇头 / 回中 / 停止 / 状态）与调节喇叭音量（设置 / 查询）。
- 官方激活：首次使用屏幕显示六位验证码，在小智控制台完成绑定，无需在源码中填写凭据。
- 音频链路：16 kHz 单声道 Opus 编解码，麦克风数字增益与客户端 VAD 参数可调。

## 快速上手

### 硬件连接

以下接线适用于 EG800Z QuecDuino V1.0 开发板，全程断电接线。

1. 将 W180 触摸屏排线正确接入开发板。

| 裸屏 FPC 脚 | 信号 | 开发板连接 | 说明 |
|---|---|---|---|
| 2 | LEDA（背光） | J3-4（3.3V）→ 5.1Ω 电阻（≥0.25W）→ FPC2 | 背光限流电阻 |
| 3 | GND | J5-4 | 共地 |
| 4 | VCI/VCC | J3-4（3.3V） | 不经过限流电阻 |
| 5 | IM0 | GND | SPI 模式 |
| 6 | IM2 | 3.3V | SPI 模式 |
| 7/8/9 | SDA3/SDA2/SDA1 | 各接 3.3V | 普通 SPI 参考图 |
| 10 | SDA0/MOSI | J5-7（模块物理 63） | SPI MOSI |
| 11 | SCK | J5-5（模块物理 49） | SPI CLK |
| 12 | RESET | J4-6（模块物理 22） | LCD 复位 |
| 13 | CS | J5-8（模块物理 64） | 片选 |
| 14 | DC | J4-4（模块物理 20） | 数据/命令 |
| 15 | CTP-SCL | J5-9（模块物理 67） | 与 ES8311 的 SCL 并联 |
| 16 | CTP-SDA | J5-10（模块物理 66） | 与 ES8311 的 SDA 并联 |
| 17 | CTP-RST（低有效） | J4-5（模块物理 21） | 触摸复位 |
| 18 | CTP-INT | 不接 | 软件轮询 |

背光限流电阻是 5.1Ω（不是 5.1kΩ）；LEDA 不能直接接地或接 5V。FPC12（LCD 复位）与 FPC17（触摸复位）是两根不同的线，不要混接。触摸（地址 0x15）与 ES8311 编解码（地址 0x18）共用 I2C1，并联即可，不要拔掉音频 I2C 线。

2. 将喇叭接入开发板扬声器接口（丝印“-spk+”）。功放使能 PA_EN 为模块物理 54（J13 需短接 1-2 才有效）；麦克风经板载 ES8311 编解码采集。

3. 将 ULN2003 驱动板排线接入开发板。

| ULN2003 信号 | 开发板数字丝印 | 排母 | 模块物理引脚 |
|---|---|---|---|
| IN1 | 4 | J6-4 | 23 |
| IN2 | 5 | J6-3 | 25 |
| IN3 | 6 | J6-2 | 28 |
| IN4 | 7 | J6-1 | 29 |

电机用独立稳压 5V 电源（建议约 1A 余量），电机供电负端、驱动板 GND、开发板 GND 共地。开发板 GPIO 输出 3.3V 逻辑，不能用 GPIO 给电机供电。

4. （可选）将 MPU6050 接入独立 I2C0：SCL = 模块 57，SDA = 模块 58，VCC 接 3.3V。

5. 使用 USB 数据线连接开发板和 PC，完成检查后上电。

### 软件部署

#### 开发环境搭建

参考 [UniRTOS 快速入门](https://docs.quectel.com/zh/UniRTOS/UniRTOS文档/快速上手/快速上手.html) 完成开发环境安装，并确认 unirtos-cli 可在 PowerShell 中使用。

#### 代码拉取

新开启 PowerShell 窗口，执行以下命令：

```PowerShell
unirtos-cli new -r unirtos-maker-examples
cd unirtos-maker-examples/xiaozhi_chat
```

#### 修改配置参数

项目默认使用官方激活（XIAOZHI_AUTO_ACTIVATE），首次上电由设备自动获取连接配置，屏幕显示六位验证码，无需在源码中填写凭据。其余可选参数集中在 main/src/xiaozhi_config.h：

| 配置项 | 说明 |
|---|---|
| XIAOZHI_AUTO_ACTIVATE | 官方激活开关，默认 1；关闭后需自行提供 xiaozhi_credentials.local.h 中的连接信息 |
| XIAOZHI_AUTO_LISTEN | 持续自动监听开关，默认 1 |
| XZ_MIC_GAIN | 麦克风数字增益，默认 16（约 +24dB） |
| XZ_VAD_SPEECH_PEAK | 语音起始判定阈值，默认 400 |
| XZ_VAD_SPEECH_FRAMES / XZ_VAD_SILENCE_FRAMES | 语音起始 / 结束判定的连续帧数 |

凭据与令牌属于敏感信息，请勿提交到代码仓库。

#### 构建项目

在 PowerShell 中执行：

```PowerShell
unirtos-cli env-setup
unirtos-cli build -m EG800ZCN_LA
```

构建成功后，命令行末尾将显示：

```Plain Text
SUCCESS: Unirtos project built successfully!
```

通过 QFlash 工具将生成的固件烧录至开发板。

#### 验证项目

1. 长按开发板电源键（S1）开机，等待屏幕点亮并完成初始化。
2. 首次使用：屏幕显示六位验证码，登录小智控制台（xiaozhi.me）完成绑定。
3. 连接建立后进入持续监听，直接说话即可对话，无需反复点击。
4. 语音指令示例：
   - “向左转 / 向右转 / 摇摇头” → 驱动头部电机；
   - “音量调大 / 音量调到最大 / 现在音量是多少” → 调节或查询喇叭音量。

## 设备端 MCP 工具

设备通过小智语音连接提供设备端 MCP 工具，无需额外端点或本地服务：

| 工具 | 功能 |
|---|---|
| self.stepper.shake_once | 摇头：左 45°→右 45°→左 45°→右 45°→中心 |
| self.stepper.turn_left / turn_right | 左 / 右转约 45° |
| self.stepper.center / stop / status | 回中 / 停止 / 状态 |
| self.speaker.set_volume / get_volume | 设置 / 查询喇叭音量（level 0–11） |

> 电机位置为软件计步估计值，无编码器/绝对零位，上电位置仅作为软件中心；实际角度受减速比、回差、丢步等影响。
